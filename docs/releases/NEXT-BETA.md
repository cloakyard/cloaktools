# CloakTools 0.6.0 Beta · candidate build 20261118.5

Draft notes for the next beta on Apple silicon running macOS 27 or later. The current public download is build 20261118.2.

- The Workbench groups tools by task and keeps Settings in a separate window. Finder Tools shows actions for folders, files and images.
- Right-click a photo to meet an upload size limit, or select an image to read its QR codes. Copy or export the current Finder selection as a list.
- Reuse selected branches of a folder, start a saved file set at the clicked destination, or compare folders by content. Select both folders to compare immediately, or start with one and choose its partner.
- Add files to a sharing collection across Finder windows. The menu-bar count opens a review where you can resolve names and save one folder of copies.
- Generate QR codes for text, web links, contacts, Wi-Fi, email, calls, text messages, map locations and calendar events. The reader can save contact and calendar documents and conceal network details.

## Distribution status

This is an ad-hoc signed development candidate. Additional Finder scopes and live Shortcuts execution still require team signing. Runtime verification covers macOS 27.2.1 on Apple silicon. Installer and updater testing of this candidate will require the eventual distribution artifacts.
