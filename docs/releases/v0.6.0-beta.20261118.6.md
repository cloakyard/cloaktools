# v0.6.0 Beta — Build 20261118.6

This beta introduces the searchable Workbench and a separate Settings window. Finder actions use the current selection to compare folders, collect files across windows, export a file list, fit an image to a size limit or read its QR codes. Structured QR creation supports contacts, Wi-Fi, calendar events and other formats. Read a contact or event QR code to save a vCard or calendar document. Reviews show the names and destinations before writing files.

**Requires Apple silicon and macOS 27 or later.** Built with Xcode 27.2 on macOS 27.2.1.

## Install and update

1. Download **CloakTools-v0.6.0-beta.20261118.6.dmg** from this release. The SHA-256 hashes of the DMG and Sparkle ZIP are in **SHA256SUMS.txt**.
2. Open the DMG, drag **CloakTools** to **Applications**, eject the disk and launch the installed app. This prerelease is ad-hoc signed and unnotarized. Review [Apple’s opening guidance](https://support.apple.com/en-us/102445) if first launch is blocked.
3. Open **Settings → About → Check for Updates**. Automatic checks and downloads are off by default. Sparkle verifies the signed website feed and the update ZIP served by GitHub.

## Dependencies and known limits

The release uses Sparkle 2.10.1 and a dependency-free Swift core. In this ad-hoc beta, Finder menus use the app workspace and Services work with accessible selected items. Additional Finder folders and live Shortcuts execution require a provisioned signing identity. Minimum-version macOS 27.0 acceptance remains open. The scoped Finder Sync menu still needs acceptance on another Mac.
