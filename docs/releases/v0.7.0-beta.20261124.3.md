# CloakTools 0.7.0 beta (build 20261124.3)

**Generate Subtitles** turns a local video or audio recording into timed SRT files. Choose the spoken language, review and edit the captions, then add any supported translations. Each exported language uses the same timestamps. Speech and translation run on your Mac. macOS may download language models on first use.

**Optimize Media** prepares smaller copies of images, PDFs, audio and video in one batch. Compare sizes before saving, reuse export recipes and undo a batch where supported. The menu-bar launcher, clipboard optimization and watched folders are optional.

## Install or update

- **Already using CloakTools?** Open **Settings → About → Check for Updates…**, then choose **Install Update** and **Install and Relaunch**.
- **First install?** Download **CloakTools-v0.7.0-beta.20261124.3.dmg** and drag CloakTools to Applications. This beta requires Apple silicon and macOS 27 or later. It is ad-hoc signed and unnotarized. [Apple’s guidance for opening apps](https://support.apple.com/en-us/102445)
- **Verify a download.** The attached **SHA256SUMS.txt** covers both the DMG and the Sparkle ZIP. Sparkle checks the signed feed and verifies the ZIP before extraction.

## Tested and known limits

The release candidate passed 252 core tests and 41 hosted app tests on macOS 27.2.1. Subtitle validation covered a full 30-minute recording, interrupted translations and matching cue times across languages. Review generated captions for recognition and translation errors. Live Shortcuts execution and additional signed Finder folder scopes require a provisioned build. macOS 27.0 and spoken VoiceOver still need live verification.
