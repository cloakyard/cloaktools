# v0.6.0 Beta — Build 20261118.2

The first public beta brings Finder file creation, templates and file sets, reviewed image/PDF/media exports, local developer tools, and optional web and mail routing. The DMG includes a drag-to-Applications installer and guide. Settings → Privacy explains local processing and update traffic.

**Requires Apple silicon and macOS 27 or later.** Built with Xcode 27.2 (27B52) on macOS 27.2.1.

## Install and update

1. Download **CloakTools-v0.6.0-beta.20261118.2.dmg** from this release. The SHA-256 hashes of the DMG and Sparkle ZIP are in **SHA256SUMS.txt**.
2. Open the DMG, drag **CloakTools** to **Applications**, eject the disk and launch the installed app. This prerelease is ad-hoc signed and unnotarized. Review [Apple’s opening guidance](https://support.apple.com/en-us/102445) if first launch is blocked.
3. Open **Settings → About → Check for Updates**. Automatic checks and downloads are off by default. Sparkle verifies the signed website feed and the update ZIP served by GitHub.

## Verification

All 224 core and eight hosted app tests passed. Debug and Release builds passed, including the embedded Finder extension. The Release host and extension carry matching versions and build numbers. The read-only DMG matched the Release app, including its code signature, and passed Finder layout and artwork validation. Sparkle signed and verified the release ZIP and feed with this product’s established key.

## Dependencies and known limits

The release uses Sparkle 2.10.1 and a dependency-free Swift core. In this ad-hoc beta, Finder menus use the app workspace and Services work with accessible selected items. Additional Finder folders and live Shortcuts execution require a provisioned signing identity. Minimum-version macOS 27.0 acceptance remains open.
