# Clop replacement on macOS

Reference installation reviewed on 23 November 2026: Clop 3.7.6, bundle identifier `com.lowtechguys.Clop`. The feature inventory draws on the installed bundle’s document and Service declarations, its ten App Intent definitions, CLI command help, its pipeline step reference and the [publisher’s feature guide](https://lowtechguys.com/clop/). Tests use generated media. The public CloakTools beta predates this work.

The acceptance target is standalone operation after removing Clop, including existing CloakTools workflows. Internet share links are excluded at the maintainer’s request. A similar control or successful compilation alone does not establish parity. Removal of Clop remains gated on the outstanding workflows below.

## Verification

Core fixtures cover decoded output types and dimensions, exact measured bytes, changed or removed sources, numbered collisions, duplicate restore attempts, rejecting changes to original files, PDF crop/uncrop, rotated moving images, changed duration, audio removal, GIF frames, common audio formats and stable-folder selection. Hosted tests cover named pasteboards and the Workbench batch lifecycle.

In the running development Workbench, a 2000 × 1400 repository screenshot measured 313 KB before preview and 145 KB at 50% scale. The review exposed Quick Look and Save 1 Copy. This is one fixture, and compression savings depend on its content.

The native app, Finder extension and bundled CLI built with Xcode 27.2 on macOS 27.2.1. The first optimizer build passed 246 core and 25 hosted tests. The expanded build passed 246 core and 29 hosted tests. The bundled CLI also measured a 312,921-byte repository image at 96,171 bytes with a 100 KB limit. The named-pasteboard test exercised automatic replacement without touching the system clipboard. End-to-end LinkDaemon execution requires a team-signed build.


The bundled CLI converted a synthetic 12-second audiovisual file to HEVC (hardware and x265), VP9 and AV1. At 25% scale and 2× speed the outputs contained 480 × 270 video and approximately six seconds of audio. A WebM result also decoded into a 240 × 134 animated GIF. MP3 and Ogg Opus accepted a −16 LUFS setting and decoded into FLAC. A 225,288-byte JPEG produced a 143,558-byte JPEG XL file, then reconstructed the exact original JPEG bytes. The four bundled executables linked only to macOS libraries.

The shared action footer was checked in the running Workbench with Optimize Media and empty PDF assembly. Return opened the PDF picker and Escape dismissed the picker and review. A hosted test measures actual button frames at 400 and 660 points of usable width. The compact floating Drop Zone was also inspected with keyboard focus, Close on the left and Choose Files on the right. A file-provider test read the exact dragged image bytes after releasing the review. Public route and interaction coverage is recorded in [the Air verification](../air/OPTIMIZATION-PRIVACY.md).
