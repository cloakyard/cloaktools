The static site built seven routes and verified 226 links, assets and anchors. The worker dry run passed. Against the local build, the repository’s Chrome link checker passed 1,080 layout and interaction states and 428 keyboard checks. Coverage included every public route, both color schemes, all eleven configured phone through desktop sizes, open navigation, enlarged text at 320 pixels, and reduced-motion rendering. A separate Chrome touch-emulation check opened and closed the mobile menu in 14 route/theme combinations and the contents disclosure in all eight combinations where it was present. These runs cover the website. Physical touch devices and spoken assistive-technology output were outside this check.
