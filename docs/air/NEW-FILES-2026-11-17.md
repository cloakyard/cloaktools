# New Files website capture verification

November 17, 2026. This replaces the landing page and root README's Conversions
preview with the actual New Files section. The shared Air layout and tokens are
unchanged. The preceding [integration audit](INTEGRATION-2026-11-17.md) remains
the baseline for the unchanged public pages and family comparison.

## Capture and cleanup

- Built app: CloakTools 0.6.0 (26), macOS 27.2.1, Apple silicon.
- Canonical pair: `assets/screenshots/new-files-{light,dark}.png`, each
  2200 × 1700 pixels, from a 1100 × 850 point window. New Files shows creation,
  saved templates, file sets, folder presets and text tools without scrolling.
- The user authorized native macOS window framing/capture. `screencapture` took
  the actual window without a pointer, shadow, arrows or annotations. Relaunching
  outside the capture tool removed its sharing badge. No image synthesis or
  retouching was used. System appearance was restored to Auto after verification.
- The website and README consume the same pair. Asset sync now names New Files
  explicitly; the old public `settings-{light,dark}.png` copies are removed.
  Historical native audit captures retain their existing documentation consumers.
- Updated the stale capture instructions in `assets/README.md`. The alt text,
  caption and intrinsic dimensions describe the new image. The image stays lazy
  loaded because it is below the hero.

## Checks and limits

Passed under Node 26.13.1/npm 12.2.2: website `verify` (Astro zero errors,
warnings or hints; seven routes; 224 local references; Air integrity and 22
portability assertions; all social cards), Wrangler dry-run, README validation,
Knip and whitespace checks. The capture is a development build, not a public
native release. No native source was changed by this screenshot replacement.

Browser coverage uses desktop Chrome and emulated input/viewports; physical touch
devices, other browser engines, spoken VoiceOver and actual browser 200% zoom
were not rerun for this asset change. Enlarged text is explicitly a root-font test.
Native Drop/Roll comparison has its own coverage ledger in Cloakyard; this page
does not certify their behavior or all native states.

Modern Web Guidance: `html` informed the intrinsic image dimensions to
“preserve aspect ratio and prevent Layout Shifts (CLS).” The existing picture
element keeps automatic light/dark selection and its fallback image.
