## Scope and remaining gates

These are actual Chrome/macOS observations and device/media emulations, not physical iPhone/iPad, Safari, Firefox or spoken screen-reader certification. Native signing, Shortcuts execution, Finder-scope acceptance and native accessibility limits remain as recorded in [the native audit](../verification/ROADMAP-IMPLEMENTATION.md). The static 404 document is checked; final hosting must still return it with HTTP 404. Hosting, DNS, preview production URLs and real social-crawler cache refresh belong to the later deployment task.

Forms, upload/drop handling, editor state, conversion progress, PWA updates, nested dialogs, shader/WebGPU recovery and transactional errors are not website surfaces. They must not be invented to imitate the native app. The complete surface ledger records applicability explicitly.

Modern Web Guidance informed the review: `responsive-design` supports content-driven sizing; `css` says “Be allergic to knowledge duplication.”, applied by retaining pinned Air tokens and shared components; `accordion` says “Do not put headings inside `summary`.” and “Do not add arrow key navigation, roving `tabindex`, or `Home`/`End` handling.” The implementation preserves these native disclosure behaviors. Air’s approved visual rules take precedence over generic styling recipes.
