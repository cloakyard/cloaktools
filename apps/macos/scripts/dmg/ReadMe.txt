CloakTools — Install Guide

INSTALL
  Drag CloakTools to Applications. Open it from Applications, then eject this disk.
  Requires an Apple silicon Mac with macOS 27 or later. Check the release notes
  for this build’s signing status and checksum. macOS checks the app on first open.
  Apple’s installation guidance: https://support.apple.com/en-us/102445

UPDATES AND PRIVACY
  Settings → About lets you check for signed updates and choose automatic updates.
  Automatic checks and downloads start off. See Settings → Privacy for details.

GET STARTED
  Choose your tools in General. Finder Integration explains how to enable
  the Finder extension and choose its workspace.
